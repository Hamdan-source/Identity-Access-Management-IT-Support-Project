## Situation

Manual onboarding took too long and increased the risk of mistakes when creating new user accounts. I built an automated onboarding pipeline to make the process faster and more consistent.

## Action

I developed a PowerShell script that takes the employee's name, department, and role as input. The script creates the Active Directory account, assigns the correct security group, forces a password change at first login, and writes an audit trail. I tested the workflow to verify that each step completed correctly.

## Reasoning

I built the script to reduce manual work and improve consistency across onboarding tasks. Automation also lowered the chance of errors in account creation and group assignment. The audit trail made the process easier to track and support.

## Result

The workflow reduced manual onboarding steps, improved consistency in account provisioning, and lowered the risk of user setup errors. New employee accounts could be created more efficiently, with clearer traceability and less administrative overhead.
