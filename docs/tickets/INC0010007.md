## Situation

I identified a shadow local admin account that was operating outside Entra ID governance. Since the account had elevated access, it required immediate investigation and mitigation to reduce security risk.

## Action

I checked Event Viewer and verified authentication activity through Event ID 4624. This confirmed the account was actively logging in outside normal identity controls. I then disabled the account to remove the security risk and documented the action.

## Reasoning

I treated the account as a security issue because it bypassed identity governance and had local admin privileges. Verifying the authentication evidence first confirmed the risk, and disabling the account was the fastest way to stop further unauthorized access.

## Result

The unauthorized admin account was removed from use, reducing the risk of unmanaged privileged access. The issue was resolved and documented as a proactive identity finding.
