Erik Larsson was starting his first day but had no Active Directory account set up, which prevented him from logging into company systems.

## Reasoning

New employee onboarding needs to be handled quickly to avoid delays on day one.

I verified everything before contacting the user so the experience was smooth and without back-and-forth issues.

Security was maintained by enforcing password reset on first login.

## Result

Erik was able to log in on the same day and begin work without delays. The account was fully set up and the ticket was closed after confirmation.
